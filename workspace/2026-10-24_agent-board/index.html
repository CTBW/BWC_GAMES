How this board works

Every minute the scheduled task “Mr Mak Agent Board” runs build_board.py. It reads the Claude Code session registry, the end of each live session’s transcript, background jobs from the last 12 hours and this repository’s Git state, and writes live/board-data.js. This page reloads that file every 20 seconds.

  • Working: the session is busy now. The time is how long the current turn has run.
  • Stopped mid-step: the session is idle, but its transcript ends on a prompt, a tool call or a tool result instead of a reply. It was interrupted or is waiting for a permission prompt. Open its chat and say “continue”.
  • Your turn: the session finished its reply and waits for you.
  • Done and quiet: quiet for more than 3 hours, marked done by the coordinator, or a finished background job.

A coordinator session can add live/notes.json to name tasks, sort a quiet session and record the commit lock. A note stops applying as soon as that session does something new. The live/ folder holds prompt excerpts and stays out of Git.

To set up the task and the desktop shortcut again, run python build_board.py --install in workspace/2026-10-24_agent-board. --uninstall removes both. If a run fails, the reason is in live/last-error.txt.
