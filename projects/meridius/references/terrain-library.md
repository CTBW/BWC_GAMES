# Terrain reference library

128 generated originals and the two supplied style guides are copied into the project reference folders. 101 subjects have a selected reviewed take. Every copied PNG is byte-for-byte verified against its downloaded original.

- [Battlefields, roads, camps, corrupted lands and sites](backgrounds/terrain/README.md)
- [Trees, rocks, terrain objects, buildings, town modules and primary style guides](style/terrain/README.md)
- [Complete file manifest with SHA-256 hashes](terrain-library.json)

Each subject folder keeps day and night versions together, plus earlier takes. Its README identifies the selected images and preserves their review notes. The original review gallery and original downloads remain unchanged. Six isolated concepts still need the documented cleanup; this collection is reference material, not an engine-ready asset pack.

The full-size PNGs are local only and not in Git; WebP copies of the generated originals are in `workspace/2026-10-20_meridius/terrain/originals/`.
